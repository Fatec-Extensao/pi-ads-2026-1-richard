# Código do protótipo web

HTML/CSS extraídos do ZIP já existente nesta pasta de Desenvolvimento Web. JavaScript compartilhado em [app.js](app.js), estilos de mensagens em [interatividade.css](interatividade.css).

Abra [index.html](index.html) no navegador ou sirva esta pasta por HTTP. Não requer npm, build ou backend.

Fluxo: Início → Responder pesquisa → código DEMO2026 → três perguntas → conclusão. Validação de obrigatórios, espaços em branco, tamanhos, e-mail, números, datas e confirmação de leitura. Avançar valida a pergunta atual; Voltar preserva as escolhas. A conclusão revalida tudo e descarta os campos. Sem JavaScript, o envio fica desabilitado.

O marcador de código utilizado fica apenas em sessionStorage; não há garantia de uso único global. Respostas e credenciais não são salvas, transmitidas ou escritas no console. Páginas RF01–RF09 e RF11–RF15 continuam demonstrações de interface, com validação quando há formulário. Não há autenticação, geração/exportação real ou integração Oracle.
