Relatório Técnico: Análise de Sistemas de Questionários

Richard de Oliveira Barra Junior, Matheus Soares e Gustavo William.

2026

1.  Introdução

Este relatório apresenta uma análise comparativa entre sistemas de questionários consolidados no mercado e o Sistema Web para Gestão de Pesquisas proposto para o Projeto Integrador I. O foco é identificar boas práticas de usabilidade, segurança e funcionalidades que possam enriquecer o desenvolvimento da solução institucional.

2.  Metodologia da Pesquisa

A pesquisa foi realizada através de análise exploratória e técnica de três plataformas: Google Forms, SurveyMonkey e LimeSurvey. Foram avaliados critérios de arquitetura, tipos de questões, segurança e a aderência ao modelo de senhas anônimas do projeto proposto.

3.  Descrição dos Sistemas Analisados

Google Forms: Ferramenta gratuita baseada em nuvem com foco em simplicidade e integração.

SurveyMonkey: Plataforma profissional de nível corporativo com análises estatísticas avançadas.

LimeSurvey: Solução open source robusta, amplamente utilizada para fins acadêmicos e pesquisas que exigem alto controle de dados.

4.  Análise Individual

    1.  Google Forms

Informações Gerais: Gratuito, empresa Google.

Características Funcionais: Criação de questionários, múltiplos tipos de questões e geração de relatórios simples com gráficos.

Características Técnicas: Plataforma Web/Mobile, arquitetura de microsserviços, integração nativa com planilhas.

Segurança: Controle de acesso por conta Google, porém o anonimato depende da configuração manual do criador.

2.  SurveyMonkey

Informações Gerais: Modelo Pago/Freemium.

Características Funcionais: Dashboard avançado, lógica de ramificação e múltiplas categorias de usuários.

Características Técnicas: Disponibilidade de API robusta para integração.

Diferenciais: Recursos avançados de análise de sentimento e modelos prontos.

3.  LimeSurvey

Informações Gerais: Open source.

Características Técnicas: Backend em PHP e banco de dados MySQL/PostgreSQL.

Segurança: Sistema de tokens para respostas únicas.

Diferenciais: Controle total sobre a privacidade dos dados.

5.  Análise Crítica

O sistema proposto apresenta funcionalidades semelhantes às plataformas analisadas, com destaque para o diferencial de geração de senhas anônimas por categoria.

6\. Conclusão

O sistema é viável e atende à demanda institucional com foco em anonimato e controle.
