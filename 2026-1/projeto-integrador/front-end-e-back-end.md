# Front-end

# Front-end é a parte visual do sistema, ou seja, aquilo que o usuário vê e interage.

**Principais linguagens:**

**HTML**  
Usado para estruturar a página, como textos, imagens, botões, formulários e links.

**CSS**  
Usado para estilizar a página, definindo cores, fontes, tamanhos, espaçamentos e layout.

**JavaScript**  
Usado para deixar a página interativa, como menus, animações, validação de formulários e comunicação com o servidor.

Também são muito usados frameworks e bibliotecas como:

**React**  
Biblioteca JavaScript para criar interfaces modernas.

**Vue.js**  
Framework JavaScript simples e bastante usado em aplicações web.

**Angular**  
Framework completo para criação de sistemas web maiores.

# Back-end

# Back-end é a parte que funciona por trás do sistema, cuidando de banco de dados, login, regras de negócio, pagamentos e segurança.

**Principais linguagens:**

**PHP**  
Muito usado em sites e sistemas web, principalmente com MySQL.

**JavaScript com Node.js**  
Permite usar JavaScript também no servidor.

**Python**  
Muito usado em sistemas web, automação, inteligência artificial e APIs.

**Java**  
Muito usado em sistemas grandes, empresariais e aplicações robustas.

**C#**  
Muito usado com a plataforma .NET, principalmente em sistemas corporativos.

**Ruby**  
Usado com o framework Ruby on Rails para desenvolvimento web rápido.

**Go**  
Linguagem moderna, rápida e bastante usada em APIs e sistemas de alta performance.
